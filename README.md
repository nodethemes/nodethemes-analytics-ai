# NodeThemes Analytics AI

**Free privacy-first analytics plugin for WordPress and WooCommerce.**

NodeThemes Analytics AI is a free, privacy-first analytics plugin for WordPress, in the style of Matomo, that runs on your own server. It is cookieless by default, never stores IP addresses and can summarise your traffic with your own OpenAI, Claude or Gemini key.

- Website: [NodeThemes Analytics AI on nodethemes.com](https://nodethemes.com/product/nodethemes-analytics-ai-pro/)
- All free plugins: [Free WordPress plugins from NodeThemes](https://nodethemes.com/free-plugins/)

## Features (free version)

- Visitors, visits, pageviews, bounce rate, real-time visitors and a visits log
- Locations from a GeoIP database on your own server
- Acquisition: channels, AI assistants (ChatGPT, Perplexity, Gemini, Claude), search engines, social and UTM campaigns
- Crawlers and AI agents log
- Goals and WooCommerce revenue, shopping path and abandoned carts
- Core Web Vitals from real visitors
- Segments, custom dashboard and CSV export
- Cookieless by default, Do Not Track / GPC, consent modes and GDPR tools
- AI summary of your traffic

## NodeThemes Analytics AI Pro

The free plugin is complete on its own. The Pro add-on, sold at [nodethemes.com](https://nodethemes.com/product/nodethemes-analytics-ai-pro/) as a yearly license with updates and support, adds:

- In-depth AI reports and chat with your analytics
- Funnels, heatmaps and session recordings
- A/B tests with significance testing
- Google Analytics 4 import and Search Console / Bing keywords
- Form, media, JavaScript-error and content tracking
- Cohorts, attribution, custom reports, alerts and scheduled e-mail reports
- Tag Manager, multiple websites and a reporting API

Pro is installed next to the free plugin; your settings and data stay when you upgrade. See the full **Free vs Pro** comparison table on the [product page](https://nodethemes.com/product/nodethemes-analytics-ai-pro/).

## Installation

1. Download the latest version from [nodethemes.com/free-plugins](https://nodethemes.com/free-plugins/). You can also click **Code → Download ZIP** above, but the version on nodethemes.com is ready to upload as it is.
2. In WordPress go to **Plugins → Add New Plugin → Upload Plugin**, choose the zip and click **Install Now**, then **Activate**.
3. New versions then appear in **Dashboard → Updates** like any other plugin.

Requirements: see the plugin header and `readme.txt`.
